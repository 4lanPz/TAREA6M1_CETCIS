# Funciones y Procedimientos en Python

## Uso de funciones y procedimientos

Para resolver los ejercicios se crearon funciones específicas que realizan tareas concretas dentro de cada sistema.  
Esto permite dividir el problema en partes más simples, haciendo que el código sea más claro y fácil de mantener.

Cada programa sigue una estructura similar:

1. **Lectura de datos**  
   Se obtienen los datos necesarios para el sistema, ya sea mediante valores 'quemados' en el código o mediante entrada del usuario.

2. **Procesamiento de la información**  
   Se aplican funciones que analizan los datos y toman decisiones según las condiciones del problema.

3. **Acciones del sistema**  
   Procedimientos que muestran o ejecutan las acciones necesarias según los resultados obtenidos.

## Implementación

Cada ejercicio se resolvió siguiendo las instrucciones del problema.  
Las funciones se encargan de procesar los datos, mientras que el programa principal coordina el flujo del sistema.

Los ejemplos incluyen sistemas simulados de:

- control de temperatura en un edificio inteligente
- gestión de inventario en un almacén
- navegación de un vehículo autónomo
- optimización de producción en una fábrica
- riego automatizado en agricultura

## Conclusión

La modularidad permite dividir problemas grandes en partes más pequeñas y manejables.  
Mediante el uso de funciones y procedimientos, los programas desarrollados son más organizados, fáciles de entender y más simples de modificar en el futuro.
