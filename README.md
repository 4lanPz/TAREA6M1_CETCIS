# Funciones y Procedimientos en Python

## Uso de funciones y procedimientos

Para resolver los ejercicios se crearon funciones específicas que realizan tareas concretas dentro de cada sistema.  
Esto permite dividir el problema en partes más simples, haciendo que el código sea más claro y fácil de mantener.

Cada programa sigue una estructura similar:

1. **Lectura de datos**  
   Se obtienen los datos necesarios para el sistema, ya sea mediante valores 'quemados' en el código o mediante entrada del usuario.

2. **Procesamiento de la información**  
   Se aplican funciones que analizan los datos y toman decisiones según las condiciones del problema.

3. **Acciones del sistema**  
   Procedimientos que muestran o ejecutan las acciones necesarias según los resultados obtenidos.

## Implementación

Cada ejercicio se resolvió siguiendo las instrucciones del problema.  
Las funciones se encargan de procesar los datos, mientras que el programa principal coordina el flujo del sistema.

Los ejemplos incluyen sistemas simulados de:

- control de temperatura en un edificio inteligente
- gestión de inventario en un almacén
- navegación de un vehículo autónomo
- optimización de producción en una fábrica
- riego automatizado en agricultura

# Resumen del uso de Funciones, Procedimientos y Modularidad

## Problema 1: Control de Temperatura en un Edificio Inteligente
En este ejercicio se utilizó modularidad separando el sistema en funciones que leen los datos de sensores, calculan la temperatura óptima, ajustan el sistema de climatización y estiman el consumo de energía. Cada función realiza una tarea específica, mientras que el programa principal coordina el proceso para cada zona del edificio.

---

## Problema 2: Gestión de Inventario en un Almacén
La solución se organizó mediante funciones que gestionan las operaciones del inventario. Se implementaron funciones para registrar entradas y salidas de productos, calcular un nivel óptimo de inventario y generar alertas de reabastecimiento. Esto permite que cada operación del inventario esté separada y sea fácil de modificar.

---

## Problema 3: Sistema de Navegación para un Vehículo Autónomo
El sistema se dividió en funciones que representan las partes principales del proceso de navegación. Se utilizan funciones para leer los sensores, detectar obstáculos, calcular la ruta y ajustar la velocidad según el tráfico. La modularidad permite que cada componente funcione de forma independiente dentro del sistema.

---

## Problema 4: Optimización de la Producción en una Fábrica
El programa se estructuró mediante funciones que monitorean el estado de las máquinas, planifican el mantenimiento, analizan el rendimiento de producción y ajustan la producción según la demanda. Esta división permite organizar mejor el sistema y facilitar cambios o mejoras en cada parte.

---

## Problema 5: Sistema de Riego Automatizado para Agricultura
En este ejercicio se usaron funciones para leer la humedad del suelo, consultar el clima, calcular la cantidad de riego necesaria y controlar las válvulas de riego. La modularidad permite que el sistema tome decisiones de riego para cada zona de forma clara y organizada.

## Conclusión

La modularidad permite dividir problemas grandes en partes más pequeñas y manejables.  
Mediante el uso de funciones y procedimientos, los programas desarrollados son más organizados, fáciles de entender y más simples de modificar en el futuro.
